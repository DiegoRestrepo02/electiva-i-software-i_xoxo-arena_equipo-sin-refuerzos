# electiva-i-software-i_xoxo-arena_equipo-sin-refuerzos

**Nombre de la Materia:** Electiva I - Software I

**Nombre del Proyecto:** XOXO Arena

**Equipo:** Sin refuerzos

**Integrantes:**
* Diego Alejandro Restrepo Sanchez
  
**Descripción:**
Este proyecto implementa un sistema en React con Vite del clasico juego de Tic Tac Toe, el cual permite a dos jugadores competir en el clásico juego de tres en raya; el proyecto incluye una interfaz amigable, validación de turnos, detección automática de ganador y reinicio de partida, ofreciendo una experiencia simple, rápida y responsiva.

**Requerimientos:**
* Node.js ^v20.17.0
* Gestor de paquetes (npm ^10.8.2)
  
**Instrucciones de compilación y ejecución:**
1. Clonar el repositorio.
2. Ejecutar `npm install` para compilar el proyecto.
3. Ejecutar `npm run dev` para iniciar la aplicación.
